# Google Play listing: translations

English is in `LISTING.md`. In Play Console: Main store listing → Manage translations → add each language, then paste. The form answers, data safety and coin pack IDs are the same for every language.

Screenshots with captions for each language are in `screenshots/<lang>/`.
